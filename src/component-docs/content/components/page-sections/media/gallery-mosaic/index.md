title: Gallery Mosaic
description: 'Photo mosaic where chosen images span two columns and two rows, giving a gallery some rhythm without a lightbox.'
overview: 'Use Gallery Mosaic when a page needs a lot of photography and a flat grid would feel monotonous. Every photo tiles to a square; flag one as a feature and it spans two columns and two rows, so the surrounding tiles flow around it. Captions are optional and sit over the bottom of a tile. The mosaic drops to two columns below 900px and a single column below 520px, where feature tiles level out with the rest.'
